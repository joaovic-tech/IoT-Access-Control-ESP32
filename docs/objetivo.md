# Objetivo do projeto

Esse projeto tem um objetivo de monitorar um comodo de uma casa , mais especificamente o meu quarto para quando alguém tentar usar meu pc o dispositivo irar capturar o movimento irar bater a foto da pessoa e usando um algotirmo de reconhecimento facial (OpenCV do python) irei saber quem tentou acessar meu PC.

## Reconhecimento Facial

Irar alguma biblioteca famosa do python que pode ser a OpenCV e e para o reconhecimento devo castrar pessoas autorizadas e caso seja uma pessoa que não está cadastrada é registrada como desconhecido.

## Inicio do prototipo

Vamos iniciar o prototipo seguindo o PLANO.md depois faremos essa atualização de reconhecimento depois (Fazer isso somente depois que o usuário/dev junior autorizar).

## Caso de uso

Dispositivo captura um movimento > registra no servidor (backend) > plataforma web recebe essa imagem e exibi (frontend) > usuário poderá ver ou deletar essa imagem.
